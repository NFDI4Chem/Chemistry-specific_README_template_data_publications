# Chemistry-specific README Template for Data Publications

This GitHub repository is part of the publication "[Chemistry-specific README template for data publications](https://doi.org/10.5281/zenodo.21619429)" by Annett Schröter, Fabian Fink, Benjamin Golub-Overbeck, Johannes Hunold, Christian Bonatto Minella, Johannes Liermann (2026), marked as [CC0 1. Universal](https://creativecommons.org/publicdomain/zero/1.0/).

## Why this template?

Data publication is becoming increasingly common in the chemistry community. While there are many chemistry-specific repositories, which allow the storage
of chemistry-specific metadata (to a different extent), most data are published in more generic repositories now.

## Getting started

1. Download or copy the [template](./NFDI4Chem_README-template.md).
2. Fill in the relevant sections with information about your data publication.
3. Include the completed README alongside your data publication (e.g., in your Zenodo upload).

## Template structure

The template is organised into sections covering:

1. General information
2. Sample information
3. Methodological information
4. Data & file overview
5. Data quality

## Contributing

This template is a living document, and we rely on the community to help it grow. Found a missing field or term definition? Have a method block we should add? Or is an important term missing? We'd love your input!

- **Report an issue or suggest a field:** Open a [GitHub Issue](../../issues)
- **Propose a change directly:** Open a [Pull Request](../../pulls)

Please describe the context or use case for any suggested addition — this helps us keep the template broadly applicable across chemistry subdisciplines. Where possible, please use controlled vocabulary and provide links to the definition of the used terms.
